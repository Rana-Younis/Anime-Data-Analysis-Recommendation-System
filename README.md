## 🚀 Project Overview
This project aims to bridge the gap between complex anime metadata and actionable insights. By analyzing thousands of titles, we uncover what makes an anime successful and build tools to help users discover their next favorite show.

## 🛠️ Tech Stack
*   **Language:** Python
*   **Data Manipulation:** Pandas, NumPy
*   **Visualization:** Matplotlib, Seaborn
*   **Machine Learning:** Scikit-learn (Random Forest, Gradient Boosting)
*   **NLP & Similarity:** TfidfVectorizer, Cosine Similarity

---

## 📊 Key Features

### 1. Exploratory Data Analysis (EDA)
*   **Source Impact:** Identified how source materials (Manga, Light Novels) influence final ratings.
*   **Studio Performance:** Ranked top-performing studios based on average user scores.
*   **Trend Analysis:** Visualized the distribution of genres and demographics (PG-13, R, etc.).

### 2. Predictive Modeling
*   Built a regression pipeline to predict **Anime Scores**.
*   Compared **Random Forest** and **Gradient Boosting** models.
*   Achieved a reliable prediction rate by engineering features like popularity, type, and source.

### 3. Smart Recommendation System
*   Developed a **Content-Based Filter** using the anime's "Genre DNA."
*   Utilized **TF-IDF Vectorization** to process textual data.
*   Implemented **Cosine Similarity** to find and rank the most similar titles to any given anime.

---

## 📈 Key Insights
*   **Quality vs. Popularity:** High popularity doesn't always guarantee a top-tier score, but specific studios consistently deliver high-quality content.
*   **Data Cleaning:** Handled extensive missing values and "Unknown" entries to ensure model stability.
*   **Feature Importance:** Popularity and Source were among the strongest predictors of an anime's success.
